# Bible Reader content — TE-Telugu

This repository contains the Bible Reader SD-card content for **TE-Telugu**.

## Directory layout

- `text/TE-Telugu/` — all Bible translations and their original nested folder structure.
- `audio/TE-Telugu/` — audio Bible book folders and chapter MP3s.
- `gospel/TE-Telugu/` — Gospel files, retaining original names such as `Gospel.txt` and `Gospel.mp3`.

Copy these folders into the root of the Bible Reader `SDCARD` staging directory.
Do not rename files or flatten directories: the firmware expects the original paths.
